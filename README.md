## 🛠️ Customization

### Change Colors
Edit the CSS variables in `style.css`:

```css
:root {
    --primary-color: #00abd5;
    --secondary-color: #222831;
    --accent-color: #393e46;
    /* ... more colors ... */
}
```

### Change Fonts
The website uses Google Fonts (Poppins). You can change this in the `@import` at the top of `style.css`.

### Add Your Information
Edit `index.html` and update:
- Your name and title
- About me text
- Contact information
- Social media links
- Project images and links
